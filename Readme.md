# Monitoring JMeter Tests with InfluxDB, Prometheus, CAdvisor, Grafana and Docker

## Tools
- **Jmeter**
- **InfluxDB**
- **Prometheus**
- **CAdvisor**
- **Grafana**
- **Docker**

---

## Objective

- Monitor JMeter tests using InfluxDB and Grafana as a visualization tool.
- Monitor resource metrics for running container instances using CAdvisor as an external data source (exporter), sending and storing them in Prometheus so they can later be used as a data source in Grafana.

---

## Additional Information

- Create a Docker Compose file containing the InfluxDB, Prometheus, CAdvisor, and Grafana images.
- InfluxDB will collect the Jmeter data and connect to Grafana to display the Jmeter metrics.
- CAdvisor will collect information on the behavior of the containers that were launched; then Prometheus will use the data generated by CAdvisor to add it to its metrics suite; and finally, Prometheus will integrate with Grafana as a data source.
- In Grafana, we will have InfluxDB as a data source, which contains data from JMeter, and Prometheus, which contains data from CAdvisor and itself.

## Steps

1. Create the Docker Compose file using the Jmeter, InfluxDB, Prometheus, CAdvisor, and Grafana images. Configure the volumes and ports correctly.
2. Have the script ready with the Backend Listener configured to InfluxDB; set the `influxdbUrl` to `http://influxdb:8086/write?db=jmeter_db`
3. Save the script in a “scripts” folder within the same directory as the Docker Compose file.
4. Start the infrastructure using Docker Compose in the Docker Desktop console:  
   ```bash
   docker compose up -d influxdb cadvisor prometheus grafana
   ```
    - `-d` runs the process in the background so you can continue working in the terminal while everything runs in the background.
5. Run the JMeter test using the following command:  
   ```bash
   docker compose run --rm jmeter
   ```
   Stop it using `CTRL+C` (or force it to stop using):  
   ```bash
   docker compose stop jmeter
   ```

Check the status of the containers:
```bash
docker compose ps
```

## Appendices

### prometheus.yml

```yaml
global:
  scrape_interval: 5s # Frecuencia de recolección

scrape_configs:
  - job_name: 'cadvisor'
    static_configs:
      - targets: ['cadvisor:8080']
```

---

### docker-compose.yml

```yaml
version: '3.8'

services:
  influxdb:
    image: influxdb:1.8
    container_name: influxdb
    ports:
      - "8086:8086"
    volumes:
      - ./influxdb_data:/var/lib/influxdb
    environment:
      - INFLUXDB_DB=jmeter_db

  cadvisor:
    image: gcr.io/cadvisor/cadvisor:latest
    container_name: cadvisor
    ports:
      - "8080:8080"
    volumes:
      - /:/rootfs:ro
      - /var/run:/var/run:ro
      - /sys:/sys:ro
      - /var/lib/docker/:/var/lib/docker:ro
      - /dev/disk/:/dev/disk:ro

  prometheus:
    image: prom/prometheus
    container_name: prometheus
    ports:
      - "9090:9090"
    volumes:
      - ./prometheus.yml:/etc/prometheus/prometheus.yml

  grafana:
    image: grafana/grafana
    container_name: grafana
    ports:
      - "3000:3000"
    depends_on:
      - influxdb
      - prometheus

  jmeter:
    image: justb4/jmeter:5.5
    container_name: jmeter
    volumes:
      - ./scripts:/scripts
      - ./results:/results
    # Este comando se ejecutará cuando hagamos 'docker compose run'
    entrypoint: ["jmeter", "-n", "-t", "/scripts/test_demoblaze.jmx", "-l", "/results/resultado.jtl"]
```
